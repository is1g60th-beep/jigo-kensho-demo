# 救急活動事後検証支援システム（デモ版）

救急活動の事後検証（活動隊の記録 → 一次検証・二重評価 → 原因分析・改善策 → 集計）の流れを試すためのデモ版です。

- アプリ：https://is1g60th-beep.github.io/jigo-kensho-demo/
- このリポジトリは公開用で、アプリのファイル（`index.html`）だけを置いています。開発は非公開のリポジトリで行っています。

## 使う前に

- **架空の症例だけで試してください。** 実際の症例・個人を特定できる情報は入力しないでください。
- 入力したデータは、開いた端末のブラウザの中（localStorage）にだけ保存されます。外部へは送信しません。他の端末とは共有されません。
- ブラウザのデータを消すと、入力したデータも消えます。「データ」画面からバックアップを書き出せます。
- ログイン画面で利用者（役割）を選ぶと、1台のブラウザで活動隊・検証者・救急担当部署を切り替えながら試せます。
- 質問項目・検証項目・確認観点は叩き台です。地域のプロトコル等との照合は済んでいません。
- 本番は閉域網内のサーバーで動かす予定で、認証・権限・操作履歴はサーバー側で管理します。このデモでは、それらを画面の中で再現しているだけです。
